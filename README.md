o banco de dados descreve um sistema de uma agência de turismo, administrando seus clientes, suas reservas e os passeios que podem oferecer em suas agendas.

1: M- relação de 1 para muitos (uma tabela se relaciona com várias, mas essas várias tabelas só podem se relacionar com uma)

tabela associativa- um segmento do banco para registrar colunas e registros dentro dele de forma organizada
primary key- um identificador único e obrigatório na tabela dentro do banco,a permitindo se relacionar com outras tabelas
foreign key- meio de relacionamento entre tabelas, utilizando suas chaves
chave composta- tabela feita para um relacionamento de M : N (muitos pra muitos). Interliga as duas foreign keys em uma só tabela
not null- condição que obriga a não deixar o registro na coluna vazio
unique- condição que exige que o registro seja único e que não possa ter outro igual no banco
alter table-comando para modificar as tabelas, seja pra adicionar, deletar ou alterar colunas
insert- comando  pra inserir registros em tabelas
update- comando para atualizar registros e alterar eles
delete-comando para deletar registros de tabelas
select-comando para consultar tabelas e suas colunas
where-condição que especifica o tipo de informação a ser requerida
and- comando que permite implementar mais condição e especificidade
count- comando para contar quantidades de registros de tabelas ou colunas
inner join- comando que utiliza os relacionamentos para interligar registros em consultas
group by- comando para agrupar registros de colunas em um só lugar
order by- comando para ordernar os registros por classes ou características
